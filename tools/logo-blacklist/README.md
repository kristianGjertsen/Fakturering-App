# Logo-blacklist

Legg midlertidige bilder som skal blokkeres i `reference-images`.

Åpne deretter `hash-generator.html` i nettleseren og velg bildene. Verktøyet
viser en 64-bits dHash som kan kopieres til `blockedLogoHashes` i
`src/lib/logoBlacklist.ts`.

Referansebildene er ikke nødvendige etter at hashene er kopiert, og kan slettes.
